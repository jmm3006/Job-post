# Job Posts

A simple Flutter app to post and browse jobs.  
Built with **Supabase + Flutter**, supporting **mobile (Android/iOS)** and **web (PWA)**.

---

## 🚀 Features
- 🔐 Authentication (Sign Up / Login with email & password)
- 📄 Create and view job posts
- 🌍 Localization support (English + Uzbek)
- 📱 Responsive design for **mobile** and **web**
- ⚡ Powered by Supabase backend

---

## 📱 Responsiveness
- App works on **Android, iOS, and Web (PWA)**
- Layout automatically adapts to different screen sizes
- Clean UI without overlaps or broken widgets
